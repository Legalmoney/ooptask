**Title**: Food Ordering System

**Description**:      
This system allows customers to browse available food items and place orders from a restaurant menu. It keeps track of the food items selected, calculates the total cost of the order, and stores order details. The system is used by customers to create orders and by the restaurant to manage food items and track orders.
